# QA E2E Tech

## QA Process Flow

<img src="images/qa-flow.png" width="900">

Plataforma orientada a la aplicación integral de procesos de Quality Assurance sobre casos reales.

El proyecto presenta un recorrido estructurado de QA, desde el análisis de requerimientos hasta la decisión final de release, integrando negocio, validación funcional, experiencia de usuario y criterios de calidad basados en evidencia.

# Descripción

QA E2E Tech expone un enfoque integral del aseguramiento de calidad aplicado sobre un caso real, evidenciando cómo QA participa activamente durante todo el ciclo de vida del producto y no únicamente en la etapa de testing.

A través de un flujo dividido en 8 etapas, el proyecto refleja una visión orientada a:

- calidad transversal
- trazabilidad
- análisis funcional
- validación orientada al negocio
- experiencia de usuario
- toma de decisiones basada en evidencia

---

# Alcance del proceso QA

El trabajo incluye:

- Análisis funcional orientado a reglas de negocio
- Diseño y ejecución de testing funcional
- Testing exploratorio
- Gestión y documentación de hallazgos
- Evaluación de riesgos
- Criterio de release basado en evidencia
- Enfoque UX integrado al proceso QA
- Trazabilidad de validaciones y decisiones

---

# Objetivo

Demostrar un enfoque profesional y estructurado de Quality Assurance aplicado sobre un escenario real, integrando perspectivas funcionales, técnicas y de experiencia de usuario dentro del proceso de validación.

---

# Enfoque aplicado

El proyecto se encuentra orientado a:

- Quality Assurance End-to-End
- Validación funcional
- Testing exploratorio

- Trazabilidad documental
